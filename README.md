# Organiza Aí Web

Sistema web Full Stack para gerenciamento e organização de tarefas pessoais.

## Sobre o projeto

O **Organiza Aí Web** tem como objetivo auxiliar o usuário na organização de suas atividades do dia a dia por meio de uma aplicação web simples e intuitiva.

O sistema permite cadastrar, consultar, editar, excluir e concluir tarefas, além de organizá-las utilizando informações como prioridade, categoria e prazo.

Este projeto está sendo desenvolvido como atividade acadêmica da disciplina de **Desenvolvimento Full Stack**.

## Funcionalidades previstas

- Cadastro de usuários
- Login
- Cadastro de tarefas
- Listagem de tarefas
- Edição de tarefas
- Exclusão de tarefas
- Marcação de tarefas como concluídas
- Definição de prioridade
- Organização por categorias
- Definição de prazo
- Filtros por status e prioridade
