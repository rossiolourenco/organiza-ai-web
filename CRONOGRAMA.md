# Cronograma de Desenvolvimento — Organiza Aí Web

## Projeto

**Nome:** Organiza Aí Web
**Tipo:** Sistema Web Full Stack
**Objetivo:** Desenvolver uma aplicação web para gerenciamento de tarefas pessoais, permitindo cadastrar, editar, excluir, concluir e organizar tarefas por prioridade, categoria e prazo.

---

## Tecnologias previstas

* Front-End: Angular
* Back-End: Java
* API: REST
* Banco de Dados Relacional: Supabase / PostgreSQL
* Banco de Dados NoSQL: Firebase Realtime Database
* Versionamento: Git e GitHub
